The ONG‑OT Vulnerability Prioritization Dataset is a reproducible pipeline that ingests real‑world CVE intelligence from authoritative public sources, applies domain‑specific Oil & Gas OT rules, and produces a versioned, provenance‑rich dataset suitable for open scientific publication.

This project integrates:

  • CISA ICS Advisories
  • CISA Known Exploited Vulnerabilities (KEV)
  • FIRST.org EPSS scores
  • CISA Vulnrichment (the full CVE record — CNA-submitted data plus CISA's own ADP enrichment)
  • MITRE ATT&CK for ICS (technique, threat-group, and malware/tool profiles)

The pipeline merges all sources on CVE ID and applies three expert‑defined YAML configurations:

  • product_class_taxonomy.yaml
  • no_patch_rules.yaml
  • compensating_controls_cpg2.yaml

These encode Oil & Gas OT product classes, no‑patch logic, and CPG 2.0 compensating controls with multiplicative risk‑reduction stacking.

What changed in v1.1

v1.0 shipped with no-patch flagging that never actually fired on real data (it matched columns that don't exist in the real source), a product-class taxonomy that mapped plc/rtu/scada to 7 generic industrial ICS vendors by bare vendor name rather than any oil & gas-specific product line, and an ATT&CK for ICS fetch that was never joined into the dataset. v1.1 fixes all three: no-patch flagging now reads real Vulnrichment CNA remediation text; the taxonomy adds a curated oil & gas product-family class (ong_product_line, weight 0.9) and re-scopes plc/rtu/scada down to specific process-control platforms actually common in oil & gas/refining (Modicon/Foxboro, PlantPAx/ControlLogix, SIMATIC/PCS 7, 800xA/Freelance/RTU560, DeltaV/Ovation, Experion PKS, CENTUM/ProSafe; weight raised 0.5 → 0.6), plus a narrow electric_adjacent class for ONG/grid interconnection-point equipment; and ATT&CK for ICS group/software profiles are now joined row-by-row where a product is explicitly named in a threat profile's own description. Full detail in the repository's docs/ folder.

Features

  • Multi‑source CVE ingestion with per-fetch provenance logging
  • Curated oil & gas OT product classification (plus a narrow electric-adjacent class)
  • No‑patch flagging based on real vendor remediation text (Vulnrichment CNA solutions/workarounds)
  • CPG 2.0 compensating control mapping
  • MITRE ATT&CK for ICS group/software matching, joined into the dataset
  • Multiplicative risk‑reduction logic
  • Versioned CSV output with a QA report and stats file
  • Automated Zenodo DOI versioning via GitHub Actions

Data Sources

All sources are public and require no authentication:

Source Purpose URL
ICS Advisory Project Clean CISA ICS advisories https://github.com/icsadvprj/ICS-Advisory-Project

CISA Vulnrichment Full CVE record: CNA data + CISA ADP enrichment https://github.com/cisagov/vulnrichment

Running the Pipeline

To produce the real dataset:

pip install -r requirements.txt
python src/pipeline.py --full --version v1.1
